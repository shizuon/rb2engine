Desktop conversion, missing-key analysis and Engine overview completion are now
available together in a compact Chinese/English interface.

## Downloads

- **Windows 10/11 x64:** extract the complete `rb2engine-0.7.0-windows-x64.zip`
  and run `rb2engine.exe`. Keep `_internal` alongside it. WebView2 is required;
  Microsoft's signed setup bootstrapper is included.
- **macOS Apple Silicon:** extract `rb2engine-0.7.0-macos-arm64.zip` and open
  `rb2engine.app`.
- **Python CLI:** install `rb2engine-0.7.0-py3-none-any.whl`. The source archive
  is also provided. This fork publishes GitHub releases and does not replace
  the separately maintained upstream PyPI package.

## New desktop features

- Choose a rekordbox USB, inspect tracks/playlists, convert and verify in one window.
- Optionally fill empty keys through a separately installed OpenKeyScan analyzer.
  Standard macOS/Windows installations are detected; existing keys are retained.
- Generate 1,024-point three-band and RGB whole-track overview waveforms during
  conversion, or fill missing overviews in an existing Engine library without
  rebuilding its metadata. Standalone completion preserves existing waveforms.
- Windows/macOS packages include Python, NumPy, FFmpeg, the AAC helper and DSP
  components. Waveform generation needs no separate compiler or FFmpeg installation.

rekordbox exports, their ANLZ waveforms and original audio remain read-only.
Database backups, source hashes, protected metadata checks, publication journals
and waveform readback verification cover Engine writes. Repeated conversion
backs up and regenerates RGB files retained from the previous database.

## Validation and scope

- The local suite passed 995 tests plus 19 subtests, with 85.72% coverage;
  physical-drive tests were excluded.
- CI covers nine OS/Python combinations, Apple Silicon native integration, and
  both desktop builds. Each desktop build exercises 13 bundled-runtime tests.
- Actual frozen applications exercise native UI controls, conversion, waveforms,
  verification, restore, standalone completion and AAC Unicode paths. Windows
  also exercises the official OpenKeyScan analyzer. Source hashes stay unchanged.
- Release publication waits for Python and both desktop builds, checks archive
  integrity, component/source presence and hashes, then supplies `SHA256SUMS`.

These are whole-track overview waveforms; scrolling high-resolution waveforms
are not generated. Existing-library waveform publication requires Engine schema
3.0.2; conversion with waveform completion enabled selects that schema. Real
DJ-player playback/display acceptance remains unverified.

Desktop packages are not signed for public distribution: macOS uses ad-hoc
signing without Developer ID notarization; Windows has no Authenticode signature.
FFmpeg LGPL licenses, complete corresponding source and build configuration are
included. OpenKeyScan itself is not redistributed.
